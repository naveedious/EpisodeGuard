Webhook Trigger
Enable Webhook Mode
When enabled, polling is a narrower fallback (active sessions only). The webhook is the primary trigger.
In Tautulli: Notification Agents → Add Webhook → Playback Start. Set Method to POST, paste the URL below, then paste the JSON body into the JSON Data field.
-
Tautulli JSON Data body (copy & paste):
{ "media_type": "{media_type}", "grandparent_title": "{show_name}", "parent_media_index": {season_num}, "media_index": {episode_num}, "grandparent_guids": ["tvdb://{thetvdb_id}"] }
Tautulli will substitute {show_name}, {season_num}, {episode_num}, and {thetvdb_id} at notification time. Only fires for media_type = episode.
