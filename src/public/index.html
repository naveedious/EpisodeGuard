Tautulli Setup
In Tautulli: Notification Agents → Add Webhook → Playback Start. Set Method to POST, paste the endpoint above, then paste the JSON body below into the JSON Data field.
JSON Data body:
{ "media_type": "{media_type}", "grandparent_title": "{show_name}", "parent_media_index": {season_num}, "media_index": {episode_num}, "grandparent_guids": ["tvdb://{thetvdb_id}"] }
Tautulli substitutes {show_name}, {season_num}, {episode_num}, and {thetvdb_id} at notification time. Only fires for media_type = episode.
Jellyfin Setup
Install the Webhook plugin in Jellyfin (Dashboard → Plugins → Catalog). Then add a webhook with the endpoint above and select the Playback Start event.
Set the template type to Default — Episode Guard detects Jellyfin payloads automatically. No JSON customisation needed.
For reliable matching, ensure your Jellyfin series have TVDB metadata populated (Dashboard → Libraries → refresh metadata). If TVDB is missing, Episode Guard falls back to title matching.
Webhook Security
When set, Episode Guard validates the X-Webhook-Token header. Leave blank to accept all requests.
Tautulli: Under HTTP Headers in your webhook agent, add X-Webhook-Token: <your secret>

Jellyfin: In the webhook plugin, set the same header under Headers.
